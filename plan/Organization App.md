# Plan
## App
TUI styled GUI
Sort by tags, collection
Mono-spaced font 
Default font: JetBrains Mono
Font options: JetBrains Mono, Cousine, B612 Mono, Sono, IBM Plex Mono, Sometype Mono
Themes: TUI, Transparent
Default palette: Rocky's Purple
Palette options: Rocky's Purple, Catppuccin, Rose Pine, Everforest, Nord, gruvbox, Rocky's Minimal
Export to .pdf
Set page as homepage
### Note Pages (Notes)
Edited markup syntax for formatting
.md for files
Inspired by Obsidian & Notion
Hardcoded tag categories: type, medium, aesthetic, industry, location, project
Backlinks
### Mood Boards (Boards)
Inspired by re-collect & pinterest
Boards
Data: title, description, url, collection, tags, audio
Images & videos supported
Hardcoded tag categories: type, medium, aesthetic, industry, location, project
### Widget Pages (Widgets)
Bento grid layout
Inspired by re-start, Trello, and Notion
Widget based organization
Widgets: date & time, weather, text, check boxes, kanban, embed, list, calendar, table, pomodoro timer
Hardcoded tag categories: type, medium, aesthetic, industry, location, project
Hardcoded Kanban categories: un-started, planning, pre-review, started, post-review, finished
